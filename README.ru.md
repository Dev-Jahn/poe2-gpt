# POE2 GPT

[English](README.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [Português (Brasil)](README.pt-BR.md)

Плагин ChatGPT и MCP-сервер для самостоятельного размещения, посвящённый **Path of Exile 2**: цены валют, поиск экипировки на официальном торговом сайте, приватные расчёты Path of Building и подбор улучшений в пределах бюджета.

**Статус: 0.9.0, экспериментальная версия.** Реализован максимум из 26 MCP-инструментов. Развёртывание на домашнем сервере, настройка доступа и проверка собственного персонажа выполняются при установке. Репозиторий не предоставляет готовый публичный сервер или опубликованный плагин в каталоге ChatGPT.

## Возможности

| Область | Реализовано |
|---|---|
| Цены валют | JSON API Scout, 17 групп категорий, выбор лиги, поиск, оценка набора предметов, кэш и сведения об источнике и времени |
| Поиск экипировки | Типизированные фильтры и поиск характеристик через экспериментальный веб-API `trade2` официального торгового сайта |
| Сохранённые билды | Тег аккаунта/имя персонажа или вложение ChatGPT, непрозрачные ID билдов, ограниченные сводки и страницы узлов пассивного дерева |
| Расчёты PoB | Закреплённая версия PoE2 PoB в приватном рабочем процессе; сравнение экипировки и проверка требований |
| Улучшения | Максимизация заданных характеристик персонажа или минимизация стоимости с ограничениями по бюджету и минимальным значениям |

Лига по умолчанию — **Forbidden Rites**, цены — **Exalted Orbs за один предмет**. Другие сезоны проверяйте через `list_leagues`. Встроенный каталог PoE2DB связывает английские и проверенные корейские названия валюты, баз предметов, классов и выбранных умений. `search_game_terms` возвращает названия и источники; отсутствующие переводы не выдумываются. Серверу не нужен ключ OpenAI API.

Движок использует закреплённую версию разработки PoB2 и данные 0.5.5 с проверкой хешей. DPS игрока, выбранного приспешника и явно настроенный FullDPS различаются. Неизвестные пассивные узлы и нерассчитанные эффекты исключают подтверждённые рекомендации улучшений. [Совместимость движка](docs/pob-engine.md).

Версия 0.9 расширяет расчёты зарядов, подношений, компаньонов и наборов оружия. Поддержанные механики и ограничения перечислены в [таблице текущей лиги](docs/league-coverage.md) (на английском).

**Коды PoB и исходный XML не передаются в MCP и контекст модели.** Приватный сервис получает данные Ninja или ссылку на вложение ChatGPT. Передавать файл на сервер не нужно. Приватные файлы читает только рабочий процесс; ChatGPT получает ID, проверенные числа и статусы. Не вставляйте код PoB в чат. [Граница данных](docs/pob-boundary.md).

## Быстрый запуск

Нужен Python 3.11+. Для рабочего процесса PoB необходимы Linux и закреплённая среда Lua.

```bash
git clone https://github.com/Dev-Jahn/poe2-gpt.git
cd poe2-gpt
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m poe2_companion.check
```

В Windows создайте окружение командой `py -3 -m venv .venv` и используйте `.venv\Scripts\python.exe`. Модуль `poe2_companion` и прежняя команда `poe2-companion` сохраняют совместимость.

Запуск MCP на домашнем сервере:

```bash
docker compose up -d --build
```

Локальный адрес: `http://127.0.0.1:8000/mcp`. Подключайте ChatGPT в браузере и настольном приложении через привязанный к аккаунту Secure MCP Tunnel либо совместимый HTTPS-сервис с аутентификацией. Cloudflare может обеспечивать OAuth; каждый экземпляр MCP допускает только одного назначенного пользователя. [Установка](docs/installation.md) · [Развёртывание](docs/deployment.md).

Для Mac mini с заблокированными входящими подключениями используйте [инструкцию Mac mini + Cloudflare](docs/mac-mini-cloudflare.md): нативные Linux-контейнеры ARM64/amd64, Managed OAuth с проверкой JWT на сервере и запуск служб после входа в macOS.

[Общий сервер для двух друзей](docs/friends.md): отдельные экземпляры MCP с аутентификацией, хранилища билдов, торговые поиски и процессы PoB на одном Mac. Домен, туннель и кэш общедоступных цен используются совместно.

Включены `.codex-plugin/plugin.json`, `.mcp.json` и каталог marketplace с источником Git для локальных хостов плагинов. Локальная установка STDIO не подключает сервер к веб-версии ChatGPT. Публикация в общем каталоге требует отдельной проверки. [Официальный формат](https://developers.openai.com/plugins/build/plugins).

Последний запрос требует приватного рабочего процесса PoB. Условия включения описаны в [справочнике инструментов](docs/tools.md).

## Ограничения

Scout предоставляет агрегированные оценки. Время загрузки не является временем исходного наблюдения цены; объявление может быть продано до покупки. Веб-API торгового сайта отличается от документированного OAuth API GGG и может измениться или отказать в доступе. Адаптер соблюдает ограничения частоты и прекращает запросы при требовании аутентификации или проверке доступа.

PoB рассчитывает сохранённую активную конфигурацию, а не текущего персонажа в игре. Рекомендуются только комбинации, прошедшие поддерживаемые проверки экипировки; неизвестные механики получают статус `indeterminate`. Оптимизация ограничена сохранёнными кандидатами, а не всем рынком. Отдельный оптимизатор характеристик предметов не рассчитывает PoB или DPS персонажа.

Поддерживаются тег аккаунта и имя персонажа либо файл `.txt`, прикреплённый в ChatGPT. Автоматическая покупка и экспорт изменённого билда отсутствуют. Работу Docker и совместимость своего PoB нужно проверить на целевом сервере.

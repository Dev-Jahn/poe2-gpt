# Localization

English is canonical. README translations currently cover Korean (`ko`), German (`de`), Russian (`ru`), and Brazilian Portuguese (`pt-BR`). Together with English, these are five language editions. Technical reference documentation remains in English.

No authoritative public ranking of PoE2 players by country was established. As a rough audience signal, the Steam review endpoint for app 2694490 returned the following language counts on 2026-09-07: English 132,665; Russian 31,760; Brazilian Portuguese 11,959; German 10,661; Polish 6,866; French 5,858; Spanish 5,807; Simplified Chinese 2,673; Thai 2,624; Japanese 1,606; Korean 226; Traditional Chinese 179. The queried parameters were `filter=all`, `purchase_type=all`, `num_per_page=1`, and the explicit language. [Valve endpoint documentation](https://partner.steamgames.com/doc/store/getreviews).

These counts describe review languages, not nationality, active players, or the entire audience. Standalone and regional clients are not represented. The initial set uses the four largest language groups observed plus Korean, as requested. Future translations can expand this coverage without presenting it as a country ranking.

When behavior changes, update all five READMEs in the same PR. Preserve commands, identifiers, numbers, links, privacy boundaries, and limitation statements. Use English game item names where an official localized mapping has not been verified. A translated README does not imply localized upstream search data or a complete item-name dictionary.
